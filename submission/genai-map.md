# GenAI usage map

Model default (from `server/config.js`): `process.env.GEMINI_MODEL || 'gemini-3.5-flash-lite'`. Only client: `server/services/gemini.js`. Prompts and response schemas: `server/prompts/*.js`.  
API: `generativelanguage.googleapis.com/v1beta/models/{model}:generateContent` with `responseMimeType: application/json` and a per-call `responseSchema`. Temperature capped at ≤ 0.4. Language instruction injected on every call (`server/services/lang.js`), requiring native script (Devanagari/Gurmukhi, never Latin transliteration). For hi/pa, stray letters from other Indic scripts are mapped into the target script (Unicode block offset); if under 20% of letters are in the target script the call is retried once, then fails with `wrong_language`. One retry on malformed JSON (`model_bad_output`); never a canned fallback.

**Efficiency:** per-route `maxOutputTokens` from `server/config.js` (summary/safety/schemes 2048, document/grievance 4096); if Gemini stops with `finishReason: MAX_TOKENS` the single retry uses 8192. Scheme answers, safety tips and summaries are cached in an in-memory LRU/TTL cache.

**Prompt-injection guard:** user content is wrapped in tags (`<facts>`, `<question>`, `<input>`, `<profile>`), free text is cleaned in zod (control/bidi chars stripped, `<`/`>` neutralised, `server/services/sanitize.js`), and every system instruction ends with a data-only rule (`DATA_GUARD`).
